## 1. 금융감독원 오픈API

적금 데이터의 본체다. 인증키 하나로 8종의 API를 쓸 수 있고, 우리는 그중 3종만 쓴다.

- 소개와 API 목록: https://finlife.fss.or.kr/finlife/main/contents.do?menuNo=700029
- 인증키 신청: https://finlife.fss.or.kr/finlife/api/finlifeApiKey/list.do?menuNo=700034

### 쓰는 API 3개

| 언제 쓰나 | API | 호출 주소 | 설명 문서 |
|---|---|---|---|
| 지금 | 적금 | `finlifeapi/savingProductsSearch.json` | [적금 API](https://finlife.fss.or.kr/finlife/api/fdrmEntyApi/list.do?menuNo=700053) |
| 지금 | 금융회사 | `finlifeapi/companySearch.json` | [금융회사 API](https://finlife.fss.or.kr/finlife/api/fncCoApi/list.do?menuNo=700051) |
| 다음 단계 | 정기예금 | `finlifeapi/depositProductsSearch.json` | [정기예금 API](https://finlife.fss.or.kr/finlife/api/fdrmDpstApi/list.do?menuNo=700052) |

주소 앞에 `http://finlife.fss.or.kr/` 를 붙인다. 끝을 `.xml` 로 바꾸면 XML로 받는다.

### 부르는 법

```
http://finlife.fss.or.kr/finlifeapi/savingProductsSearch.json
  ?auth={인증키}          ← 발급받은 32자리
  &topFinGrpNo=020000     ← 은행. 저축은행은 030300
  &pageNo=1               ← 한 번에 100건씩
```

세 API 모두 변수가 같다. `financeCd`(은행 코드나 이름)를 넣으면 그 은행만 볼 수 있다.

**권역 코드**: 020000 은행 · 030200 여신전문 · 030300 저축은행 · 050000 보험 · 060000 금융투자

### 응답에서 쓰는 값

적금 API는 상품 정보(`baseList`)와 금리 옵션(`optionList`)을 따로 준다. 한 상품에 기간·적립 방식별로 옵션이 여러 개 붙는다.

**상품 정보**

| 필드 | 뜻 | 화면에서 |
|---|---|---|
| `kor_co_nm` / `fin_prdt_nm` | 은행명 / 상품명 | 상품 이름 |
| `spcl_cnd` | 우대조건 원문 | AI가 읽는 대상, 화면에 원문 표시 |
| `join_way` | 가입 방법 | 영업점·인터넷·앱 |
| `join_member` | 가입 대상 | 나이·자격 판정 |
| `join_deny` | 가입 제한 (1 제한없음 / 2 서민전용 / 3 일부제한) | 가입 전 확인 |
| `max_limit` | 월 최고 한도 | 넣을 수 있는 금액 제한 |
| `mtrt_int` | 만기 후 이자율 | 가입 전 확인 |
| `etc_note` | 유의사항 | 가입 전 확인 |
| `dcls_month` / `dcls_strt_day` | 공시월 / 공시 시작일 | 근거 표시 |

**금리 옵션**

| 필드 | 뜻 |
|---|---|
| `save_trm` | 기간 (개월) |
| `rsrv_type` | S 정액적립식 / F 자유적립식 |
| `intr_rate_type` | S 단리 / M 복리 |
| `intr_rate` | 기본금리 |
| `intr_rate2` | 최고우대금리 |

**금융회사 API**에서는 `homp_url`(홈페이지)과 `cal_tel`(콜센터)만 쓴다.

### 주의할 점 (공식 예제에서 확인)

- 금리가 **비어 있는 옵션**이 실제로 있다. 값이 없으면 그 옵션은 계산에서 뺀다.
- 금융회사 API 예제에 **은행명과 홈페이지 주소가 어긋난 사례**가 있다(우리은행에 신한카드 주소). 링크는 은행명과 대조해 검수한다.
- 한 번에 100건까지. 개인 인증키는 하루 조회 횟수 제한이 있다.

### 실제 응답으로 확인한 값 (2026-09-13 · 은행 권역 전체 페이지)

`DisclosureClient`로 금융회사와 적금 API를 각각 마지막 페이지까지 호출했다. 두 응답 모두
1페이지가 마지막 페이지였으며, 수신본은 `docs/samples/saving-products.sample.json` 형식으로 변환할 수 있었다.

| 확인한 것 | 결과 |
|---|---:|
| 금융회사 페이지 | 1 |
| 적금 상품 페이지 | 1 |
| 금융회사 | 18 |
| 상품 | 59 |
| 상품 식별자(은행코드·상품코드) | 59 |
| 금리 옵션 | 181 |
| 내부 상품 변환 성공 | 59 |
| 내부 금리 옵션 변환 성공 | 181 |
| 기본금리·최고금리 누락 옵션 | 0 |

따라서 이번 호출에서는 상품 59건과 금리 옵션 181건이 모두 내부 모델로 변환됐다. 다음 페이지는 없었다.

| 확인한 것 | 결과 |
|---|---|
| 우대조건(`spcl_cnd`)이 있는 상품 | 59건 중 56건 |
| 우대조건이 "없음/해당없음"인 상품 | 3건 — SC제일은행 퍼스트가계적금, 산업은행 KDB 기업정기적금·KDB 자유적금 |
| `spcl_cnd` 본문에 `%p` 수치까지 적힌 상품 | 53건 |
| `spcl_cnd` 길이 | 2자("없음") ~ 201자 |
| 최고금리 > 기본금리인 옵션 | 181건 중 155건 |
| 기본금리 = 최고금리 (우대 없음) | 26건 |
| 금리가 빈 옵션 | 이번 회차 0건 (있을 수 있으므로 처리는 유지) |

우대 폭(`intr_rate2 - intr_rate`) 상위: 토스뱅크 키워봐요 31일적금 9.0%p · 케이뱅크 궁금한 적금 6.0%p ·
카카오뱅크 한달적금 5.5%p · 경남은행 오면우대!하면우대! 5.1%p · KB 특★한 적금 4.0%p.

**`spcl_cnd` 의 %p 합과 옵션의 우대 폭은 일치하지 않을 수 있다.** 중복 적용 불가 조건, 계약기간별 차등이 섞이기 때문이다.
구조화할 때 항목 합계를 신뢰하지 말고 옵션의 우대 폭을 상한으로 두고 검증한다.

### 오류 코드

| 코드 | 뜻 | 대응 |
|---|---|---|
| 000 | 정상 | — |
| 010·011·012·013 | 인증키가 미등록·중지·삭제·샘플 | 키 확인 |

### 쓰지 않는 API

연금저축, 주택담보대출, 전세자금대출, 개인신용대출, 개인사업자대출. 서비스 범위 밖이다.

## 2. 전국은행연합회 소비자포털

API에 없는 값을 여기서 받는다. 포털은 자동 접근을 막아두어서, 아래 주소는 **성격만** 확인했다. 요청 규격은 브라우저 개발자 도구로 확인해야 한다.

| 받을 것 | 페이지 |
|---|---|
| 적금 전월취급평균금리 | https://portal.kfb.or.kr/compare/receiving_neosave.php |
| 적금 중도해지금리 | https://portal.kfb.or.kr/compare/receiving_neosearch_2.php |
| 정기예금 금리 | https://portal.kfb.or.kr/compare/receiving_neosearch.php |
| 청년도약계좌 은행별 금리 | https://portal.kfb.or.kr/compare/receiving_youth_leap.php |
| 청년미래적금 은행별 금리 | https://portal.kfb.or.kr/compare/receiving_youth_future.php |

### 전월취급평균금리란

은행이 **직전 달에 실제로 판 상품의 평균 금리**다. 포털 안내문 기준으로 저축 기간과 관계없이 12개월 기준이고, 만기 시 주는 우대금리는 빠져 있다. 공시 시차 때문에 지금 금리와 다를 수 있다.

광고하는 최고금리 옆에 이 값을 같이 보여주면, 실제로 사람들이 받은 금리가 얼마인지 드러난다.

### 적금 엑셀 내려받기 (직접 호출해 봄, 2026-09-09 · 18건 수신)

```
POST https://portal.kfb.or.kr/compare/receiving_neosave_search_result_excel_new.php
헤더: Referer = .../receiving_neosave.php , User-Agent = 브라우저 문자열
본문: InterestType=Simple1
      BankValue=은행코드를 | 로 연결
      EXPIRATION=2      (12개월)
      InterestMonth=12
받는 것: 엑셀 파일 — 은행, 상품명, 기본금리, 최고금리, 전월취급평균금리, 만기후금리, 우대조건, 가입방법
```

페이지의 내려받기 기능을 그대로 쓴 것이라 공개 문서가 없다. 페이지가 바뀌면 다시 확인해야 한다.

## 3. 청년도약계좌 (참고)

서민금융진흥원: https://ylaccount.kinfa.or.kr/

만기 5년(60개월), 월 70만원 한도 자유납입, 월 최대 3만 3천원 정부기여금, 이자소득 비과세.
가입 대상은 가입일 기준 19~34세(병역 기간 최대 6년은 나이 계산에서 뺌), 총급여 7,500만원 이하이면서 종합소득금액 6,300만원 이하.

은행별 금리는 위 은행연합회 청년도약계좌 페이지에서 받는다.

## 4. 왜 크롤링이 필요한가

금감원 API에는 **전월취급평균금리와 중도해지금리 필드가 없다.** 정책상품(청년도약계좌·청년미래적금)은 은행이 공시 대상으로 등록하지 않아 API에 아예 없다. 그래서 이 셋만 은행연합회에서 받는다. 나머지는 전부 API로 충분하다.

## 5. 다음에 확인할 것

은행연합회 페이지 4개(중도해지금리·정기예금·청년도약계좌·청년미래적금)의 요청 규격. 브라우저에서 조회 버튼을 눌러 어떤 요청이 나가는지 확인한 뒤 이 문서에 적는다.
