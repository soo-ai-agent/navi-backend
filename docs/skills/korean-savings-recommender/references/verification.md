## 원본 대비 고친 것

1. **인증키**: `FINLIFE_API_KEY` 단독 → 환경 변수 우선 + `backend.ini` `DISCLOSURE_AUTH_KEY` 폴백 (`load_auth_key()`). 키 값은 문서에 적지 않음.
2. **질문 순서 표**: 5번과 14번이 중복(둘 다 "추천 기준") → 14번 삭제, 13개로 정리. 6번 행에 "건너뛰는 조건" 셀이 두 번 들어간 오타 → 한 개로 정리. 0-2 문구 표의 14번도 삭제.
3. **iM함께적금 상한 표**: "0.85%p 초과" → 항목 합계가 상한과 정확히 같음(0.85%p)으로 수정.
4. **미끼 금리 표**: 현재 1위인 토스뱅크 키워봐요 31일적금(10%) 추가, 세후이자 예시를 "월 50만원 넣고 싶은 사용자 기준" 관점으로 재계산. 카카오 자유적금 월 한도는 50만원이 아니라 300만원(etc_note 실측)임을 반영.
5. **`intr_rate` 빈값**: "실제로 있다" → "현재 회차 0건, 방어는 유지"로 완화.
6. **상한 폴백 문구**: "상한 표기를 못 찾으면 `intr_rate2`가 상한" → 가산분 상한은 `intr_rate2 - intr_rate` 가 정확하므로 수정.
7. **navi 맥락 단락 추가**: 서비스 기능은 백엔드(POST /api/v1/wishes)가 담당, 이 스킬은 수동 상담·데이터 검증용.
8. **코드 정본 분리**: SKILL.md 본문의 Python 코드 → scripts/finlife_saving.py 로 이동(단일 원본), 본문은 포인터만.
9. err_cd 실측 정보 추가: 오류여도 HTTP 200, `total_count` 가 문자열 "0" 으로 옴.
